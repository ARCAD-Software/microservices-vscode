## Web Servers & Services in ARCAD-Transformer Microservices

ARCAD Transformer Microservices is designed to automate the deployment of REST web services for IBM i ILE objects (programs or service programs). 
Leveraging IBM's Integrated Web Services Server (IWS), this tool simplifies the process of defining, managing, and deploying web services, enhancing productivity and minimizing manual intervention.

> **Reference**  
> For further information, refer to the [Integrated Web Services Server Administration and Programming Guide](https://www.ibm.com/docs/en/iws).

### Features
- **[Manage Web Server](web-servers.md)**: create and manage IWS Web Services Server.
- **[Manage Deployed Web Services](web-services.md)**: deploy new Web services powered by externalized procedures developed through ARCAD-Transformer Microservices.
